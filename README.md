# Calculadora de Parâmetros TENS & FES (nome provisório)
## Colaboração com o curso de Fisioterapia
Este trabalho está sendo feito em conjunto com os alunos de Fisioterapia da UniBH. Um dos grupos de alunos solicitou um sistema que ajudasse com o estudo e a utilização dos aparelhos TENS (Estimulação Elétrica Nervosa Transcutânea) e FES (Estimulação Elétrica Funcional). Dentre as especificações do sistema, foram requisitadas várias features como um atlas de eletrodos, um simulador de aparelhos, um prontuário para acompanhamento de clientes, uma biblioteca de conteúdo para estudo, uma assistente de IA para praticar, entre outras. Entretanto, dadas as limitações de tempo e recursos, a ideia é desenvolver uma versão reduzida do sistema solicitado.

## O que será desenvolvido
O sistema desenvolvido será um aplicativo que auxiliará diretamente o estudante e o profissional de fisioterapia a usar os aparelhos TENS e FES. Nele, o usuário poderá inserir as necessidades do paciente e ele poderá consultar os parâmetros a serem programados no dispositivo e a localização dos eletrodos a serem colocados no paciente.
